# ArtiSys Almoxarifado UI v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modernizar as telas existentes do Almoxarifado sem alterar domínio, API ou persistência.

**Architecture:** Manter o frontend estático atual e preservar IDs/handlers. Concentrar a evolução em tokens CSS, classes semânticas, ajustes estruturais no HTML e renderização visual de rótulos/status no JavaScript.

**Tech Stack:** HTML, CSS, JavaScript ES modules, Node `node:test`.

**Spec:** `docs/superpowers/specs/2026-09-12-ui-v2-design.md`

## Global Constraints
- Não executar GitHub Actions.
- Não alterar contratos da API/domínio/banco.
- Preservar `[hidden]{display:none!important}`.
- Manter valores `ENTRY`, `EXIT`, `ADJUSTMENT`, `TRANSFER` enviados à API.
- Não adicionar dependências pagas ou serviços externos.
