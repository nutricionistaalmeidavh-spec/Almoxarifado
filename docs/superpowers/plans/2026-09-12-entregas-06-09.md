# Entregas 06–09 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar interface operacional, API/persistência LAN, barcode local e relatórios/impressão do MVP.

**Architecture:** O PC principal serve PWA + API local no mesmo processo. O domínio existente continua responsável por estoque/inventário; novos adapters cuidam de catálogo, persistência em arquivo, relatórios e UI.

**Tech Stack:** Node 22+, HTML/CSS/ESM, `html5-qrcode` 2.3.8, módulos ArtiSys já integrados.

**Spec:** `docs/superpowers/specs/2026-09-12-entregas-06-09-design.md`

## Global Constraints
- Core obrigatório R$ 0.
- Sem cloud ou API paga obrigatória.
- Funcionamento local e LAN sem internet.
- Desktop Windows é o host principal; celular/tablet usam a PWA.
- Não rodar CI remoto a cada commit.
