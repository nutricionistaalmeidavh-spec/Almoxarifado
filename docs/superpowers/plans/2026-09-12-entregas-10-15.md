# Entregas 10–15 Implementation Plan

**Goal:** implementar autenticação/RBAC, backup, compras, gestão, estoque avançado e custos/reposição no núcleo local do Almoxarifado.

**Architecture:** serviços de domínio separados sobre o repositório local existente. A API compõe os serviços e aplica autenticação/autorização. A UI consome apenas a API autenticada.

**Verification:** testes unitários dos serviços, integração HTTP local, regressões de relatórios/schema e `node --check` dos arquivos alterados.

## Ordem
1. Expandir o repositório preservando compatibilidade de estado.
2. Implementar autenticação/RBAC e backup.
3. Implementar compras e gestão.
4. Estender movimentos e implementar estoque avançado.
5. Implementar custos/reposição e valorização por custo médio.
6. Integrar rotas HTTP autenticadas e UI.
7. Atualizar schema, documentação e testes.
8. Executar verificação local ampla antes de integrar no `main`.
