# Entregas 21–24 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gerar, validar e distribuir o ArtiSys Almoxarifado 1.0.0 como instalador Windows x64 sem sistema de licença.

**Architecture:** O runtime Electron existente continua sendo a aplicação distribuída. `electron-builder` produz o NSIS x64; scripts de release verificam instalação, API, UI, persistência, hash e manifesto; um workflow final, acionado apenas no fechamento, executa os gates Linux/Windows e publica o mesmo artefato aprovado. O Google Drive recebe exclusivamente o artefato baixado desse workflow.

**Tech Stack:** Node.js 22, Electron 43.4.1, electron-builder 26.15.3, Playwright 1.62.1, NSIS, GitHub Actions Windows/Linux, módulos ArtiSys pinados em `vendor/utilidades`.

**Spec:** `docs/superpowers/specs/2026-09-12-entregas-21-24-design.md`

## Global Constraints

- Versão final: `1.0.0`.
- Artefato: `ArtiSys-Almoxarifado-Setup-1.0.0.exe` Windows x64.
- Sem licença, chave, ativação, limite de máquina, servidor de licença ou demo bloqueada.
- Dados do usuário ficam fora da pasta de instalação e devem sobreviver a reinstalação/upgrade/desinstalação padrão.
- Sem cloud obrigatória para operação.
- GitHub Actions só é acionado no fechamento final.
- Homologação física de câmera, leitor, impressora, balança e máquina de cliente continua fora do escopo.
